# LOONA

Игра лунных фаз для ВКонтакте: портретный экран 540×960, статичный рекламный баннер сверху.

## Локальный запуск

Дважды щёлкните `run_game.bat` (нужен Python) или выполните `python run_local.py` и откройте http://localhost:8000.

## Развёртывание на Vercel

Импортируйте репозиторий на [vercel.com](https://vercel.com/new) — настройки уже лежат в `vercel.json`, менять в мастере ничего не нужно. Vercel выполнит `npm run build` и выложит папку `build/`. В отличие от хостинга VK, на Vercel видео разрешено, поэтому в эту сборку попадает и видео-интро `intro.mp4`.

Адрес развёрнутой игры можно указать в настройках игры в VK вместо хостинга VK, либо взять с него только видео: `https://<проект>.vercel.app/intro.mp4` (см. «Видео-интро» ниже).

## Публикация во ВКонтакте

### Что уже сделано в коде

- **VK Bridge** (`vk-bridge.min.js`, версия 3.0.2) и интеграция в `vk.js`: `VKWebAppInit`, статичный рекламный баннер сверху (`VKWebAppShowBannerAd`, `banner_location: 'top'`, `layout_type: 'resize'` — экран игры уменьшается на высоту баннера, баннер ничего не перекрывает). Если объявлений нет, показ повторяется каждые 30 с (до 5 попыток).
- **Прогресс** (пройденное обучение, открытые карты-джокеры) дублируется в хранилище VK (`VKWebAppStorageSet/Get`): на хостинге VK адрес игры меняется при каждой выкладке, и `localStorage` при этом пустеет.
- **Кнопка «Поделиться»** на экране результатов внутри VK открывает окно `VKWebAppShare` со ссылкой на игру.
- Убрано всё, что вело на Google: статистика дудла, кнопки поиска «фазы Луны» и «Подробнее».
- Пути к файлам относительные, звук не требует файла (на хостинге VK аудио и видео запрещены).
- Шрифты Google загружаются не дольше 3 с, иначе игра стартует со шрифтом-заменой.

Вне VK (локальный запуск через `run_game.bat`) всё работает как раньше, VK-функции просто молчат.

### Как опубликовать на хостинге VK

1. Создайте игру на [dev.vk.com](https://dev.vk.com) (тип «Игра») и узнайте её ID.
2. Впишите ID в `vk-hosting-config.json` вместо `0` в поле `app_id`.
3. В настройках игры укажите **Отображение → Мобильный формат → Элементы управления: «Над окном»**. Без этого баннер сверху не покажется — VK поддерживает `top` только в таком режиме.
4. Один раз установите зависимости (нужен Node.js):

   ```bash
   npm install
   ```

5. Соберите и выложите игру на хостинг VK:

   ```bash
   npm run deploy
   ```

   Команда сначала собирает папку `build/`, затем загружает её. При первой выкладке утилита покажет ссылку для авторизации — откройте её в браузере и подтвердите. На вопросы об обновлении адресов (`update prod urls?` и т. д.) отвечайте «да».
6. Проверьте игру по адресу `https://vk.com/app<ID>` — на компьютере и в мобильном приложении VK.

Только собрать, без выкладки: `npm run build`.

### Если баннер не показывается

1. Проверьте настройку игры: dev.vk.com → **Приложения → ваша игра → Настройки → Отображение → вкладка «Мобильный формат» → Элементы управления: «Над окном»**. Без неё баннер сверху (`banner_location: 'top'`) не работает.
2. Откройте игру по адресу `https://vk.com/app<ID>#debug`. Внизу экрана появится панель со всеми запросами к VK и ответами на них. Строка `✗ VKWebAppShowBannerAd …` содержит код и причину ошибки, `← VKWebAppShowBannerAd {"result":true,…}` означает, что VK баннер показал.
3. Пока игра не прошла модерацию, реклама показывается в тестовом режиме — это нормально.

### Видео-интро

На хостинге VK нельзя размещать видео, поэтому при `npm run build` / `npm run deploy` файл `intro.mp4` в сборку не попадает, и игра после загрузки сразу переходит к обучению. Чтобы интро было, выложите `intro.mp4` на любой HTTPS-хостинг (например, на Vercel, см. выше) и перед сборкой укажите ссылку в `build-vk.mjs` (константа `INTRO_VIDEO_URL`) или в переменной окружения `LOONA_INTRO_URL`.
